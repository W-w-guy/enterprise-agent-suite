# 43/50 评测对照与成本看板

## 客户原话要什么
「实现六组对照实验结果汇总、回归差异与成本统计。」

## 交付形态
`python3 run.py 1530 board <实验目录> <基线组> <输出目录>`

输入：`experiments/*.jsonl`，每行一个样本结果
```json
{"group":"g1","run_id":"r1","id":"q001","ok":true,"latency_ms":820,"tokens_in":300,"tokens_out":120}
```
输出：`board.md`（人看）、`board.csv`（进 Excel）、`diff.json`（接 CI）。

## 四个刻意的选择

**1) 成本按 token 重算，不读原始 cost 字段。**
客户的表里 cost 口径经常混（有的含缓存、有的不含），直接汇总等于把不同口径加起来。
这里按价目表（每百万 token 单价）重算，换价目表能整表重出。

**2) 通过率给 Wilson 区间，不给裸百分比。**
六组样本量往往不一样，20 个样本的 90% 和 200 个样本的 90% 不是一回事。
区间重叠时不判「变好/变差」，只报「样本不足」并给出每组需要多少样本。

**3) 显著变差时命令返回非零退出码。**
能直接接 CI，不需要人肉看看板。

**4) 脏行不整批失败。**
一行坏 JSON、`ok` 写成 `"yes"`、`latency_ms` 是负数，都进「未计入的脏行」表并带文件名与行号。

## 已修的缺陷
- 「无差异」与「样本不足」混为一谈（会让人以为改动无效）
- 金额用微美元整数累加，避免 `0.1+0.2=0.30000000000000004`

## 边界
不做统计检验之外的因果推断，不接外部实验平台 API。
