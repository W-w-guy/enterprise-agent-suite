# 19/50 经营数据 Agent

## 客户原话要什么
「配置经营指标查询和分析 Bot，区分事实、计算与建议。」

## 交付形态
`python3 run.py 1506 brief <指标字典.csv> <指标值.csv> <指标> <本期> <上期> <去年同期> <输出.md> [分子:分母]`

## 三段分离，不许混着说

- **事实**：直接来自明细，带 `doc_id`。例：`毛利 在 2026-08 为 400000.00 USD [doc_gp]`
- **计算**：由事实按公式推出，公式印在括号里。例：`2026-08 环比 -60.0% (2026-07 → 2026-08) ((本期-上期)/上期)`
- **建议**：规则命中的判断，必须写出命中哪条规则。例：`(命中规则 R1（mom <= -0.10）)`

## 关键设计：数据不齐就不给建议

如果本期、上期、去年同期里缺任何一项，报告会明说
`数据不齐（…），本报告不给建议` —— 拿不全的数据给建议，比不给建议更糟。

指标字典里没登记的指标，直接拒绝分析（而不是猜一个口径）。

## 真实数据里踩到的（已修）

| 输入 | 旧行为 | 现行为 |
|---|---|---|
| 期间写 `2026-8` / `2026/08` | 当成另外两个期间，报「缺数据」 | 归一成 `2026-08` |
| 期间写 `2026Q3` | 当成一个期间 | 明确拒绝，让你先换算 |
| 同期间重复两行 | 静默取后者 | 保留首行，报出被忽略的行号 |
| 上期填 0 | 报「缺上期」 | 报「环比无定义（不是缺数据）」 |
| 万元与元混填 | 印出「环比 +88361%」并给「维持现有节奏」 | 量级校验触发，抑制趋势建议 |
| 文件是 GBK | UnicodeDecodeError 崩 | 自动识别 |

## 边界
不做预测与外推；规则表 R1–R3 是示例，客户按自己口径改。
